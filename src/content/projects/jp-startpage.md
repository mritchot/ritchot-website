A startpage with a pseudo-Japanese terminal aesthetic with funtionality that I wish regular startpages or new tabs had. Functional and efficient, with the ability to customize links and efficiently navigate to those links within 3 keystrokes. Comes with the ability to customize a quote rotation, and images. Everything is configurable from the 設定 CONFIG tray in the corner. A setup syncs across machines through the browser profile, or across browsers through a secret GitHub Gist.

Started as a project five years ago which was a bit more cumbersome. Whenever I wanted to change a link or image I had to do some sweeping code edits. However, as that happened so rarely the time to value tradeoff was never worth undertaking. However, LLMs compress the work so much that I was able to complete all the features I wanted to within a day and even go as far as publish it on the [Chrome Web Store](https://chromewebstore.google.com/detail/jp-startpage/njhkdmembkbbcagahaiknbdfomnloaio) and [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/jp-startpage/) as JP-Startpage.
